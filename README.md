# Create Schedule — จัดตารางเรียนส่วนตัว

เว็บแอปสำหรับนักเรียน/นักศึกษา: ใส่วิชาและ section ที่เปิดสอน (วัน เวลา ห้อง) แล้วโปรแกรมจะหา **ทุกชุด section ที่เวลาไม่ชนกัน** ให้เลือก

- ล็อก section ที่ต้องการแน่ ๆ ไว้ได้ โปรแกรมจะเลือกให้เฉพาะวิชาที่เหลือ
- เรียงผลลัพธ์ตาม: ช่วงว่างระหว่างคาบน้อย, ไปเรียนน้อยวัน, ไม่เรียนก่อน/หลังเวลาที่กำหนด
- ถ้าจัดไม่ได้ จะบอกสาเหตุ: วิชาคู่ไหนชนกันทุก section หรือถอนวิชาไหนแล้วจะจัดได้
- แสดงเป็นตารางรายสัปดาห์ + กด "ล็อกชุดนี้" เพื่อยืนยันชุดที่เลือก
- ข้อมูลเก็บในเบราว์เซอร์ (localStorage) ส่งออก/นำเข้าเป็น JSON ได้
- ไม่มี dependency ไม่ต้อง build — HTML + CSS + JavaScript ล้วน

## วิธีใช้งาน

เปิดผ่าน web server (ดับเบิลคลิก `index.html` ตรง ๆ จะไม่ทำงาน เพราะเบราว์เซอร์ไม่โหลด ES module จาก `file://`):

```bash
npx serve .            # หรือ
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` (หรือพอร์ตที่ขึ้น) กด **โหลดตัวอย่าง** เพื่อดูการทำงาน

> ถ้าเปิด GitHub Pages ให้ repo นี้ (Settings → Pages → Deploy from branch `main` / root) จะใช้งานผ่านเว็บได้เลย
> หมายเหตุ: บัญชี GitHub ฟรี เปิด Pages ได้เฉพาะ repo สาธารณะ

## ทดสอบ

```bash
npm test               # ใช้ node:test ในตัว (Node 18+) ไม่ต้องติดตั้งอะไร
```

## รูปแบบข้อมูล (JSON ที่ส่งออก/นำเข้า)

```json
{
  "courses": [
    {
      "code": "MATH101",
      "name": "แคลคูลัส 1",
      "sections": [
        {
          "id": "1",
          "sessions": [
            { "day": "MON", "start": "09:00", "end": "10:30", "room": "SC-201" },
            { "day": "WED", "start": "09:00", "end": "10:30", "room": "SC-201" }
          ]
        }
      ]
    }
  ],
  "locks": { "MATH101": "1" },
  "prefs": { "minimizeGaps": true, "preferDaysOff": false, "noBefore": "09:00", "noAfter": "" }
}
```

`day` เป็น `MON` `TUE` `WED` `THU` `FRI` `SAT` `SUN`

## หลักการทำงาน

| ส่วน | ไฟล์ |
|---|---|
| แปลง/ตรวจเวลา | `src/time.js` |
| ตรวจข้อมูล, ตรวจชน, ค้นหา, วินิจฉัย, จัดอันดับ | `src/scheduler.js` |
| หน้าเว็บ | `index.html`, `styles.css`, `src/app.js` |
| บันทึก/นำเข้า | `src/storage.js` |

- **เวลาชน**: คาบ A กับ B ชนกันเมื่อ วันเดียวกัน และ `A.start < B.end` และ `B.start < A.end` — คาบที่ต่อกันพอดี (จบ 10:00 / เริ่ม 10:00) **ไม่นับว่าชน** section สองตัวชนกันถ้ามีคาบใดคาบหนึ่งชนกัน
- **ค้นหา**: backtracking โดยเริ่มจากวิชาที่มี section น้อยที่สุดก่อน (ตัดกิ่งได้เร็ว) และ cache ผลการตรวจชนของแต่ละคู่
- **จำกัดผลลัพธ์**: หยุดที่ 5,000 ชุด ถ้ามีมากกว่านั้นจะแจ้ง และการเรียงจะครอบคลุมเฉพาะ 5,000 ชุดแรกที่ค้นเจอ — ล็อก section เพิ่มเพื่อลดจำนวน
- **วินิจฉัยเมื่อจัดไม่ได้**: (1) คู่วิชาที่ทุก section ชนกัน (2) ถ้าไม่มีคู่แบบนั้น ลองถอนทีละวิชาแล้วบอกวิชาที่ถอนแล้วจัดได้
- **การเรียง**: ความสำคัญ คาบนอกช่วงเวลาที่ต้องการ → จำนวนวันที่ไปเรียน (ถ้าเลือก) → ช่วงว่างรวม (ถ้าเลือก) เงื่อนไขเวลาเป็นแบบ "ไม่อยาก" ไม่ใช่ "ห้าม" ชุดที่ผิดเงื่อนไขจะถูกเรียงไปท้าย ไม่ถูกตัดทิ้ง

## ข้อจำกัดที่รู้อยู่

- ยังไม่รองรับเงื่อนไขผูก section บรรยายกับแล็บ (เช่น บรรยาย sec 1 ต้องคู่แล็บ sec 1–2) — ตอนนี้ให้ใส่บรรยาย+แล็บเป็นคาบใน section เดียวกัน
- ยังไม่คิดเวลาเดินทางระหว่างตึก
- ยังไม่มีปุ่มแก้ไขคาบ (ลบแล้วเพิ่มใหม่)
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว ไม่ sync ข้ามเครื่อง (ใช้ส่งออก/นำเข้า JSON)
